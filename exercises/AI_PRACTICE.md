# 用 AI 陪练，而不是让 AI 代写

把下面模板和当前报错一起发给 AI：

```text
我在完成“虾搞象棋”第 X 课练习。
请先用一句话解释这个函数的输入契约与输出契约，再指出当前失败最可能对应哪一条契约。
只给我一个最小修改提示和一个可打印观察的中间变量，不要直接给完整答案。
我修改并重新运行后，会把下一条错误发给你。
```

如果连续两次没有进展，再追加：

```text
请用一个 2×2 或 3×3 的最小例子手算一遍，但仍不要贴完整函数。
```

全部通过后，最后问：

```text
请审查我的实现是否正确处理了形状错误、越界、空结果和方向翻转，只列测试用例，不改代码。
```
